# Циклы

## Цикл while

while - цикл с пред-условием. JS проверит выполнение условия и после пойдёт выполнять код. После снова проверит, снова выполнит и по кругу :)

```
while (условие) {
    код...
}
```

## Цикл for

for - цикл с началом, условием и шагом

```
for (начало, услови, шаг) {
    код
}
// Пример
for (let i = 0; i < 10; i++) {...}
```

### Задачи 2

1. «Обратный отсчёт перед запуском кода» (Обратный отсчёт i--)
Легенда: Вы нажимаете Enter, чтобы запустить свой первый продакшн-код.
Задание: Напишите цикл for (let i = 10; i > 0; i--).
Внутри цикла выводите: "Обратный отсчёт: " + i + "..."
Добавьте условие: если i === 3, выведите: "⚠️ ТРИ! Последняя возможность отменить!"
После цикла выведите: "🚀 ЗАПУСК! (или ошибка компиляции, как повезёт)"
2. «Прыжки ленивого кузнечика» (Шаг i += 3)
Легенда: Кузнечик хочет добраться до поляны, но лень двигаться часто.
Задание: Напишите цикл for (let i = 0; i <= 20; i += 3).
Внутри цикла выводите: "Прыжок! Текущая позиция: " + i + " см."
Если i === 12, выведите: "Ой, я устал. Отдыхаю 5 минут." (но цикл продолжается)
После цикла выведите: "Кузнечик добрался до поляны и сразу лёг спать."
3. «Таблица умножения для идиотов» (Вложенные циклы)
Легенда: Вы решили помочь школьникам, но делаете это максимально абсурдно.
Задание: Напишите вложенный цикл: внешний for (let i = 1; i <= 3; i++), внутренний for (let j = 1; j <= 5; j++).
Внутри выводите: "Сколько будет " + i + " x " + j + "? " + (i * j) + " (если ты ещё не уснул)"
Если i === 2 && j === 3, выведите: "⚠️ ВНИМАНИЕ: Это был сложный пример! Отдыхаем."
После внешнего цикла выведите: "Поздравляю! Вы выучили таблицу умножения до 3x5. Теперь вы гений."
4. «Попытки починить принтер» (Оператор break)
Легенда: Принтер не работает. Вы пытаетесь его починить, но терпение на исходе.
Задание: Напишите цикл for (let attempt = 1; attempt <= 10; attempt++).
Внутри цикла выводите: "Попытка " + attempt + ": дёргаю провод, молюсь, бью по корпусу..."
Добавьте условие: если attempt === 4, выведите: "💥 ХВАТИТ! Я сдаюсь. Иду покупаю новый принтер. (break)" и прервите цикл.
Если цикл завершился без break (что невозможно с текущим условием, но пусть ученики попробуют убрать break), выведите: "Вы терпеливый человек. Принтер починён (или вы сошли с ума)."
5. «Фильтр нечётных чисел» (Оператор continue)
Легенда: Вы считаете что-то важное, но только чётные числа приносят удачу.
Задание: Напишите цикл for (let i = 1; i <= 10; i++).
Внутри цикла: если i % 2 !== 0 (нечётное), выведите: "⚠️ " + i + " — нечётное число! Пропускаю, это плохая примета. (continue)" и переходите к следующей итерации.
Для чётных чисел выводите: "✅ " + i + " — отличное чётное число! Записываю в блокнуд удачи."
После цикла выведите: "Фильтрация завершена. Теперь только чётные числа принесут мне богатство."
6. «Фибоначчи, но с настроением» (Две переменные в цикле)
Легенда: Вы решили посчитать числа Фибоначчи, но каждое число имеет своё настроение.
Задание: Создайте переменные a = 0, b = 1. Напишите цикл for (let i = 0; i < 8; i++).
Внутри цикла:
Выводите: "Число: " + a + ". Настроение: " + (a < 5 ? "грустное" : a < 10 ? "нормальное" : "величественное")
Обновляйте: let temp = a + b; a = b; b = temp;
После цикла выведите: "Фибоначчи гордился бы вами. Или нет. Кто его знает."
7. «Факториал ленивого математика» (Накопление результата)
Легенда: Вам нужно посчитать факториал, но вы делаете это с сарказмом.
Задание: Создайте переменную factorial = 1. Напишите цикл for (let i = 1; i <= 5; i++).
Внутри цикла:

Выводите: "Шаг " + i + ": " + factorial + " (я всё ещё верю, что это имеет смысл)"
После цикла выведите: "Факториал 5 = " + factorial + ". Зачем я это считал? Кто я? Где я?"
8. «Игра "Угадай число" (но вы жульничаете)» (Цикл с условием выхода)
Легенда: Вы играете в игру, где нужно угадать число от 1 до 10, но вы знаете ответ заранее.
Задание: Создайте переменную secretNumber = 7. Напишите цикл for (let guess = 1; guess <= 10; guess++).
Внутри цикла:
Если guess === secretNumber, выведите: "🎉 УРА! Я угадал с " + guess + "-й попытки! (На самом деле я знал ответ с самого начала)" и прервите цикл (break).
Иначе выводите: "❌ " + guess + " — не то. Пробую ещё..."
После цикла выведите: "Я гений! Или просто подглядел ответ. Но кто считает?"
