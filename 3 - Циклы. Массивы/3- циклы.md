## Цикл while

while - цикл с пред-условием. JS проверит выполнение условия и после пойдёт выполнять код. После снова проверит, снова выполнит и по кругу :)

```
while (условие) {
    код...
}
```

## Цикл for

for - цикл с началом, условием и шагом

```
for (начало, услови, шаг) {
    код
}
// Пример
for (let i = 0; i < 10; i++) {...}
```

## Массивы

Массив - это способ хранить много данных в одной переменной

```
let a = [1, 2, 3, 4, 5]
const b = ["Привет", "Я второй элемент", "Я третий"]
```

Индексация начинается с 0

```
[5, 7, 9, 13, 8]
 ^  ^  ^  ^   ^
 0  1  2  3   4   
```
