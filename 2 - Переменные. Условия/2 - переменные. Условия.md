# Переменные. Условия.

## Переменные

Переменная - контейнер, в который можно положить значения. Бывают двух видов

```
let a; // обычная переменная
const a; // константа - неизменяемая переменная

var a; // устаревший способ задавать обычные переменные (области видимости)
```

## Условия

Иногда код нужно выполнить только при каком-то условии (как media запросы)

Для этого служит условный блок

```
if (условие 1) {
    код
} else if (условие 2) {
    код
} else {
    код, если предыдущие два условия не выполнились
}
```

Условия пишутся с помощью булевых операторов

```
a > b // больше
a < b // меньше
a >= b // больше или равно
a <= b // меньше или равно
a == b // равно (одинарное равно уже занято определением переменной)
a != b // не равно (так как зачеркнутое равно никак не поставишь)
```

## Составные условия

Иногда одной проверки недостаточно. Можно - писать условие в другом условии. А можно - воспользоваться составными условиями.

```
(условие 1) && (условие 2) // И - должны выполниться оба
(условие 1) || (условие 2) // Или - должен выполниться хотя бы один
!(условий) // Не - условие должно не выполниться
```
